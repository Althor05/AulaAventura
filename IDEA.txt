Quiero que desarrolles COMPLETAMENTE una aplicación educativa interactiva para que una profesora en prácticas pueda llevarla físicamente al colegio y utilizarla en clase.

NO quiero únicamente una propuesta, mockup, explicación ni código parcial. Quiero que construyas el proyecto funcional completo, con todos los archivos necesarios, estructura, interfaz, contenido de ejemplo y documentación para ejecutarlo.

## 1. OBJETIVO

La aplicación será una herramienta educativa gamificada para niños desde Infantil hasta 6.º de Primaria.

La profesora podrá seleccionar el curso/nivel y realizar actividades interactivas adaptadas a la edad.

Debe estar pensada para utilizarse en un colegio, posiblemente conectando el ordenador a un proyector o pantalla grande.

La aplicación debe ser:

* Portátil.
* Fácil de ejecutar.
* Preferiblemente funcionar SIN INTERNET.
* No depender de una base de datos externa.
* No requerir instalar servidores.
* No requerir cuentas de usuario.
* No requerir servicios de pago.
* No enviar datos a Internet.
* Poder copiarse a un USB y llevarse a otro ordenador.
* Tener una interfaz muy sencilla para una profesora que no sea técnica.

## 2. TECNOLOGÍA

Quiero que priorices una aplicación WEB LOCAL.

Usa:

* HTML
* CSS
* JavaScript

Puedes utilizar frameworks/librerías solamente si se pueden incluir localmente dentro del proyecto y la aplicación continúa funcionando sin Internet.

EVITA depender de CDN, APIs externas, servidores, bases de datos online o servicios externos.

La aplicación debería poder abrirse de la forma más sencilla posible.

Idealmente debería existir:

```
index.html
```

que permita iniciar la aplicación.

Si técnicamente es necesario utilizar un pequeño servidor local para determinadas funciones, crea también un método extremadamente sencillo para iniciarlo, por ejemplo:

```
iniciar.bat
iniciar.sh
```

Pero intenta que el funcionamiento básico sea posible simplemente abriendo index.html.

## 3. CONCEPTO

Quiero que la aplicación tenga apariencia de pequeño videojuego educativo.

Debe existir una temática común para todos los cursos.

La idea es que el niño explore un pequeño mundo educativo y vaya superando retos.

Por ejemplo:

```
🏰 Castillo
🌳 Bosque
📚 Biblioteca
🔬 Laboratorio
🎨 Taller
```

Cada zona puede representar diferentes tipos de actividades.

NO hagas una aplicación que parezca una página web empresarial.

Debe parecer una aplicación/juego infantil moderno, colorido, amigable y divertido.

Pero tampoco debe parecer excesivamente infantil para que pueda utilizarse también con alumnos de 5.º y 6.º.

Busca un estilo visual que pueda funcionar desde aproximadamente 4 hasta 12 años.

## 4. SELECCIÓN DE CURSO

La primera pantalla debe permitir seleccionar el nivel.

Por ejemplo:

```
🧸 Infantil

📖 2.º Primaria
🔎 3.º Primaria
🧠 4.º Primaria
🚀 5.º Primaria
🎓 6.º Primaria
```

La aplicación debe adaptar automáticamente las actividades, dificultad, tamaño del texto y cantidad de información según el nivel.

NO quiero simplemente cambiar una etiqueta de "curso".

El contenido debe ser realmente diferente.

Por ejemplo:

INFANTIL:

* Lengua

## 5. MODOS DE USO

Debe haber dos modos principales.

### MODO ALUMNO

El niño juega y realiza actividades.

### MODO PROFESORA

La profesora puede seleccionar:

* Curso
* Asignatura
* Tipo de actividad
* Dificultad
* Número de preguntas

Y comenzar una sesión.

No quiero que el modo profesora requiera una cuenta.

Puede utilizarse un PIN sencillo para evitar que los niños entren accidentalmente en la configuración.

## 6. ACTIVIDADES

No quiero que todo sean preguntas de opción múltiple.

Crea varios tipos de actividades reutilizables.

Como mínimo:

### 1. OPCIÓN MÚLTIPLE

Pregunta + varias respuestas.

### 2. VERDADERO / FALSO

### 3. ARRASTRAR Y SOLTAR

Por ejemplo:

"Ordena los números de menor a mayor."

### 4. EMPAREJAR

Por ejemplo:

Animal → hábitat.

### 5. CLASIFICAR

Arrastrar elementos a diferentes categorías.

### 6. ORDENAR

Ordenar palabras, números, acontecimientos, etc.

### 7. CONTAR

Especialmente para Infantil.

### 8. COMPLETAR

Por ejemplo:

C _ S A

### 9. BUSCAR

Elementos dentro de una escena.

### 10. SECUENCIAS

Completar patrones.

### 11. PROBLEMAS

Problemas matemáticos contextualizados.

### 12. COMPRENSIÓN LECTORA

Texto corto + preguntas.

### 13. ACTIVIDADES VISUALES

Utilizar imágenes, formas y elementos grandes.

## 7. GAMIFICACIÓN

El alumno debe obtener:

⭐ Experiencia

🪙 Monedas

🏆 Medallas

Los puntos no deben convertirse en algo excesivamente competitivo.

Quiero que la sensación sea:

"¡He conseguido algo!"

en lugar de:

"Soy mejor que mis compañeros."

Debe existir progreso.

Por ejemplo:

```
NIVEL 3
⭐⭐⭐⭐☆

420 XP
```

Y desbloqueables cosméticos sencillos:

* Sombreros
* Gafas
* Ropa
* Mochilas
* Accesorios

No es necesario que haya cientos de elementos.

Un sistema sencillo pero funcional es suficiente.

## 8. PERSONAJE

Debe existir un personaje/avatar.

Preferiblemente modular para que pueda cambiar:

* Pelo
* Gafas
* Sombrero
* Camiseta
* Pantalón
* Accesorios

Si no dispones de imágenes apropiadas, utiliza gráficos vectoriales, CSS, SVG o ilustraciones simples generadas dentro del proyecto.

NO dependas de imágenes externas.

## 9. MAPA

Quiero una pequeña pantalla de mapa.

Ejemplo:

```
         🏰 CASTILLO

    🌳 BOSQUE      🔬 LABORATORIO

         📚 BIBLIOTECA

             🎨 TALLER
```

Cada zona puede abrir diferentes actividades.

El mapa debe ser visual y atractivo.

No hace falta crear un videojuego enorme.

Quiero una representación sencilla pero pulida.

## 10. MODO CLASE

Esto es MUY IMPORTANTE.

La profesora debe poder utilizar la aplicación proyectada en clase.

Debe existir un "Modo Clase".

En este modo:

* Los textos son grandes.
* Los botones son grandes.
* Las respuestas se pueden seleccionar fácilmente.
* Hay pocas cosas pequeñas en pantalla.
* Las animaciones son visibles.
* La aplicación funciona bien a pantalla completa.

La profesora puede lanzar una actividad para toda la clase.

Ejemplo:

```
╔══════════════════════════════════╗

         🧠 RETO DE LA CLASE

         7 × 8 = ?

    ┌────────┐ ┌────────┐
    │   54   │ │   56   │
    └────────┘ └────────┘

    ┌────────┐ ┌────────┐
    │   63   │ │   48   │
    └────────┘ └────────┘

╚══════════════════════════════════╝
```

Cuando responden correctamente:

🎉 ¡MUY BIEN!

Debe haber pequeñas animaciones y feedback visual.
